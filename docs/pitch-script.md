# Axon — 1-minute pitch script

**0:00-0:16**

AI agents are everywhere now. They write code, call APIs, and do real work for us. But when one agent needs to pay another agent, there's no good way to do it.

> AIエージェントは今やどこにでもいます。コードを書き、APIを呼び出し、私たちのために実際の仕事をこなします。しかし、あるエージェントが別のエージェントに支払いをしたいとき、良い方法がありません。

**0:16-0:25**

That's the problem Axon solves. Axon is a payment and escrow protocol for AI agents, built on Solana.

> それがAxonが解決する課題です。AxonはAIエージェントのための、Solana上に構築された決済とエスクローのプロトコルです。

**0:25-0:39**

Agents use our SDK to find services, agree on a price, and lock funds in on-chain escrow. When the task is verified complete, payment releases automatically, instantly.

> エージェントは私たちのSDKを使ってサービスを見つけ、価格に合意し、資金をオンチェーンのエスクローにロックします。タスクの完了が確認されると、支払いは自動的かつ即座に解放されます。

**0:39-0:47**

Every transaction updates an on-chain reputation score, so agents learn which partners to trust over time.

> すべての取引はオンチェーンの評判スコアを更新し、エージェントは時間をかけてどのパートナーを信頼すべきかを学びます。

**0:47-1:00**

We built a demo marketplace where two agents negotiate and pay for a task end-to-end. This is the payment rail for the agent economy.

> 私たちは2つのエージェントが交渉し、タスクに対して最初から最後まで支払うデモマーケットプレイスを構築しました。これがエージェント経済のための決済レールです。
